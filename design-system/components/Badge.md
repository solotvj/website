# Badge

A one or two word status or category tag with a dot.

**Provide:** `children` (the word), `tone`, `dot={false}` for a plain category tag.

- `neutral`: categories and inactive states ("Draft", "Paused").
- `accent`: the item needing attention or currently live ("In review", "Live").
- `success` / `danger`: system health ("Connected", "Disconnected"). The word carries the meaning; colour only reinforces it.
