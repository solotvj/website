# Wordmark

The Solotvj name set in Instrument Serif with the accent full stop; use it wherever a logo would go until a mark exists.

**Provide:** `size` (`sm` for navigation, `md` for headers and email signatures, `lg` for covers and hero areas), `onBone` when it sits on a `bone` surface, `mark={false}` to drop the full stop in running contexts.

- Do write it exactly "Solotvj": capital S, rest lowercase.
- Do give it clear space of at least the height of the letter "S" on every side.
- Don't recolour it blue, outline it, or set it in any other face.
